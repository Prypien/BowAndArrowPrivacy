# Bow & Arrow — Website (GitHub Pages)

Marketing website for the iOS game **Bow & Arrow**, served via GitHub Pages.

- `index.html` — marketing site (React/design system at runtime). Datenschutz & Impressum also in the ☰ menu (DE/EN).
- `privacy.html` — standalone Privacy Policy / Datenschutzerklärung (**App Store privacy URL**).
- `impressum.html` — standalone Impressum / legal notice.
- `terms.html` — optional Terms of Use / Nutzungshinweise (legacy; Impressum is on `impressum.html`).
- `assets/`, `uploads/`, `_ds/`, `support.js` — assets and runtime for the marketing site.

## Live URLs (after deploy)

| Page | URL |
|------|-----|
| Marketing | `https://prypien.github.io/BowAndArrowPrivacy/` |
| Datenschutz | `https://prypien.github.io/BowAndArrowPrivacy/privacy.html` |
| Impressum | `https://prypien.github.io/BowAndArrowPrivacy/impressum.html` |

**Before go-live:** In App Store Connect, set the Privacy Policy URL to `…/privacy.html` (not `/` alone — root becomes the marketing site).
